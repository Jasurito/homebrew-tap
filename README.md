# Jasurito's Homebrew tap

```sh
brew install --cask jasurito/tap/eyebreak
brew install --cask jasurito/tap/barmod
```

| Cask | Description |
| --- | --- |
| [eyebreak](https://github.com/Jasurito/EyeBreak) | Menu bar reminder for the 20-20-20 eye strain rule |
| [barmod](https://github.com/Jasurito/BarMod) | Windows-style popup for hidden menu bar icons |

`Casks/eyebreak.rb` is updated automatically by each EyeBreak release. `Casks/barmod.rb` is updated by BarMod's `Scripts/release.sh`.
